# Scope

## In scope

- Main Sequence project orchestration
- project-local specialist delegation
- generated repo context
- static parent prompt plus child-only policy
- reusable workflow prompts
- tutorial regression verification
- Playwright-backed GUI validation for the tutorial workflow
- standard external web access through `pi-web-access`
- TypeScript-only repo-local runtime

## Out of scope

- patching Pi core
- hidden multi-agent execution on every internal turn
- automatic parallel specialist orchestration as a general default
- full release automation and packaging workflow
- a full RAG stack or vector database
- turning Astro into a generic website crawler

## Why

Astro is meant to be a clear, inspectable orchestration starter.

That means:

- real wiring, yes
- unnecessary framework complexity, no
