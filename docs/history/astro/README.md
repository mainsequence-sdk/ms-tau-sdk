# Historical Deployment-Project Archive

This directory preserves the former product's decisions, implementation plans, references,
investigations, and changelog for provenance. It is non-normative: paths, settings, images, runtime
roles, package names, and operational procedures described here are not supported SDK contracts.
Provider-specific image-build and push procedures were deleted instead of retained in this archive.

Current documentation starts at [the SDK documentation index](../../README.md), and current
decisions are listed in [the active ADR index](../../adrs/README.md).
