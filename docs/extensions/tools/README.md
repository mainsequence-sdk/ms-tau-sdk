# Extension tools

These pages document Astro's repo-owned tools under `pi/extensions/tools/`.

## Tools

- Root Astro currently exposes `pi/extensions/tools/runtime-info`.
- Main Sequence package tools are delivered by `tmp_ms_pi` and are not mirrored here.

## Notes

- Tool contracts documented here are Astro-specific. They are layered on top of Pi's core tool
  system and do not replace Pi core tools.
- Retired tools are documented only from the pages that explain their removal; they are not part of
  the active tool surface.
