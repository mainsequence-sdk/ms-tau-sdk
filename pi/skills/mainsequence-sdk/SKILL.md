Use this skill when the user asks about the `mainsequence-sdk` library, its behavior, APIs, or documentation.

## Research flow

1. Prefer official Main Sequence SDK documentation and the upstream repository.
2. If a specific file or doc is referenced, fetch that content directly before answering.
3. Be explicit about versions and dates when relevant.

## Output expectations

- Provide clear, direct answers grounded in the SDK docs or source.
- Call out uncertainty or missing information.
